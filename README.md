# 🏥 営業ロープレ道場 — 事務長攻略トレーニング

医用機器(放射線X線機器)営業向けの音声ロールプレイング練習Webアプリ。
営業担当者(あなた)と顧客役の事務長(AI)が音声で対話し、
1回のロープレにつき**1つのテーマだけ**のフィードバックを受けられます。

> 営業は本番、ロープレは練習。明日の商談前に5分だけ。

## 使い方

**ログイン不要・インストール不要。** `index.html` をブラウザで開くだけで使えます。
GitHub Pagesなどの静的ホスティングで公開すれば、URLをクリックするだけで
iPhone Safari / Windows Chrome・Edge から利用できます。

1. **シーンを選ぶ** — オープニング / ヒアリング / 製品説明 / 価格提示 / クロージング
2. **事務長モードを選ぶ** — 😊やさしい / 😐普通 / 😠忙しくて怖い
3. **評価テーマを1つ選ぶ** — 専門用語NG / 値引き切り返し / 結論から簡潔に / 質問の意図
4. **5〜20分の音声ロープレ** — マイクで話すと事務長が音声で応答(テキスト入力にも切替可)
5. **結果発表** — 達成度◎○△× / 良かった発言の引用 / 改善点1つ+言い換え例 / 100点スコアと称号

## 特徴

- **完全クライアントサイド**: サーバー・APIキー不要。事務長AIはルールベース対話エンジン、採点はヒューリスティック自動採点
- **音声はブラウザ標準API**: 音声認識(SpeechRecognition) + 音声合成(speechSynthesis)。非対応環境では自動的にテキスト入力へフォールバック
- **専門用語チェック**: DICOM・管電流・被ばく線量などを使うと事務長が必ず「それって何ですか？」と聞き返す
- **値引き不可の縛り**: 自社は業界No.2。値引きを口にすると「他社はもっと下げてくれる」と揺さぶられる
- **ゲーム性**: スコア・称号・連続実施記録(localStorage)

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 全画面を持つシングルページ |
| `style.css` | スマホ縦画面ファーストのレスポンシブCSS |
| `js/data.js` | 商材・シーン・モード・テーマ・セリフの全定義(**商材変更はここだけ**) |
| `js/engine.js` | 事務長AI(対話エンジン)と自動採点 |
| `js/speech.js` | 音声認識・合成ラッパー(フォールバック付き) |
| `js/app.js` | 画面フロー・タイマー・チャットUI・記録 |
