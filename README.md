# 🏥 営業ロープレ道場

医療機器営業向けの音声ロールプレイング練習Webアプリ。営業担当者(あなた)と
顧客役AIが音声で対話し、1回のロープレにつき**1つのテーマだけ**の
フィードバックを受けられます。

> 営業は本番、ロープレは練習。明日の商談前に5分だけ。

このリポジトリには**2つの練習シナリオ**が同居しています。どちらも独立した
URLで公開され、同時に利用できます。

| シナリオ | URL(サブディレクトリ) | 顧客役 | 商材 |
|---|---|---|---|
| ①事務長攻略トレーニング | `/jimucho/` | 病院事務長(佐藤さん) | X線透視診断装置「SONIALVISION G4シリーズ」約4,500万円〜 |
| ②循環器内科部長攻略トレーニング | `/bucho/` | 循環器内科部長(高橋先生) | 血管撮影装置「Trinias OPERA B8」約1億円 |

GitHub Pagesで公開した場合、それぞれ
`https://<ユーザー名>.github.io/<リポジトリ名>/jimucho/` と
`https://<ユーザー名>.github.io/<リポジトリ名>/bucho/` のURLになります
(リポジトリ直下にはトップページを置いていません)。

## シナリオ設定

共通: プレイヤーは医療機器メーカー(業界2位)の営業担当。**値引きは一切不可**。
値引きを口にすると「他社はもっと下げてくれる」「それなら他社にする」と
揺さぶられ、断って価値で切り返すと「値段だけじゃないってことね」と前に進む。

- **①事務長**: 医療従事者ではない。DICOM・管電流・被ばく線量などの専門用語は
  知らず、使うと「それって何ですか？」と聞き返す(同じ用語は1回だけ)。
  関心は経営面(コスト・稼働率・差別化・安全性・運用負担)。
- **②循環器内科部長**: 臨床には精通しているが、放射線科領域(DICOM・X線防護・
  設置工事・装置スペック)は知らない。関心は患者目線(被ばく・処置時間・
  安全性)と経営目線(稼働率・収益・差別化)。

## 使い方

**ログイン不要・インストール不要。** `/jimucho/index.html` または
`/bucho/index.html` をブラウザで開くだけで使えます。

1. **シーンを選ぶ** — オープニング / ヒアリング / 製品説明 / 価格提示 / クロージング
2. **相手のモードを選ぶ** — 😊やさしい / 😐普通 / 😠忙しくて怖い(「5分しかない」・遮り・ストライク3回で商談打ち切り)
3. **評価テーマを1つ選ぶ** — 専門用語NG / 値引き切り返し / 結論から簡潔に / 質問の意図
4. **5〜20分の音声ロープレ** — マイクで話すと相手が音声で応答(テキスト入力にも切替可)
5. **結果発表** — 達成度◎○△× / 良かった発言の引用 / 改善点1つ+言い換え例 / 100点スコアと称号

## 特徴

- **完全クライアントサイド**: サーバー・APIキー不要。相手役AIはルールベース対話エンジン、採点はヒューリスティック自動採点
- **音声はブラウザ標準API**: 音声認識(SpeechRecognition/webkitSpeechRecognition) + 音声合成(speechSynthesis)。非対応環境・認識失敗時は自動的にテキスト入力へフォールバック
- **専門用語チェック**: シナリオごとに設定した専門用語を使うと必ず「それは何ですか？」と聞き返される
- **値引き不可の縛り**: 断って価値で切り返すと商談が前に進む
- **ゲーム性**: 100点スコア・称号・実施回数・連続日数・自己ベスト(localStorage、2シナリオ共通で記録)

## ファイル構成

対話エンジン・音声入出力・画面制御は2シナリオで共有し、商材データと
静的ページ本文だけをシナリオごとに分離しています。

| ファイル | 役割 |
|---|---|
| `js/engine.js` | 相手役AI(`RoleAI`、対話エンジン)と自動採点(**共有**) |
| `js/speech.js` | 音声認識・合成ラッパー、フォールバック付き(**共有**) |
| `js/app.js` | 画面フロー・タイマー・チャットUI・記録(**共有**) |
| `style.css` | スマホ縦画面ファーストのレスポンシブCSS(**共有**) |
| `jimucho/index.html` | ①事務長版のページ本文 |
| `jimucho/js/data.js` | ①の商材・専門用語・台詞・評価テーマ別フィードバック文言の全定義 |
| `bucho/index.html` | ②部長版のページ本文 |
| `bucho/js/data.js` | ②の商材・専門用語・台詞・評価テーマ別フィードバック文言の全定義 |

新しいシナリオ(第3の顧客役など)を追加する場合は、`data.js`と`index.html`の
組を新しいサブディレクトリにもう1組作るだけで済みます(`js/engine.js`等の
共有ロジックは変更不要)。

## 開発

ローカル確認: `python3 -m http.server` でリポジトリ直下を配信し、
`/jimucho/` と `/bucho/` それぞれをブラウザで開く。
エンジン単体は `node -e "$(cat jimucho/js/data.js js/engine.js) …"` のように
シナリオのdata.jsと共有engine.jsを連結して、ブラウザなしでも確認できます。

再構築・拡張用のスキルを `.claude/skills/sales-roleplay-app/SKILL.md` に用意しています。
