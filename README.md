# 🏥 営業ロープレ道場 — 循環器内科部長攻略トレーニング

医療機器(血管撮影装置)営業向けの音声ロールプレイング練習Webアプリ。
営業担当者(あなた)と顧客役の循環器内科部長(AI)が音声で対話し、
1回のロープレにつき**1つのテーマだけ**のフィードバックを受けられます。

> 営業は本番、ロープレは練習。明日の商談前に5分だけ。

## シナリオ設定

- **あなた** = 医療機器メーカー(業界2位)の営業担当。**値引きは一切不可**。
- **商材** = 血管撮影装置「Trinias OPERA B8」。本体のみ(オプションなし)で約1億円。
  競合は業界No.1シェアの他社製品で、価格では対抗できない。
- **顧客** = 循環器内科の部長(高橋先生)。臨床には精通しているが、
  放射線科領域(DICOM・X線防護・設置工事・装置スペック)は知らない。
  専門用語を使うと「それは何ですか？」と聞き返される(同じ用語は1回だけ)。
  関心は患者目線(被ばく・処置時間・安全性)と経営目線(稼働率・収益・差別化)の
  メリットへの「翻訳」。

## 使い方

**ログイン不要・インストール不要。** `index.html` をブラウザで開くだけで使えます。
GitHub Pagesなどの静的ホスティングで公開すれば、URLをクリックするだけで
iPhone Safari / Windows Chrome・Edge から利用できます。

1. **シーンを選ぶ** — オープニング / ヒアリング / 製品説明 / 価格提示 / クロージング
2. **部長モードを選ぶ** — 😊やさしい / 😐普通 / 😠忙しくて怖い(「5分しかない」・遮り・ストライク3回で商談打ち切り)
3. **評価テーマを1つ選ぶ** — 専門用語NG / 値引き切り返し / 結論から簡潔に / 質問の意図
4. **5〜20分の音声ロープレ** — マイクで話すと部長が音声で応答(テキスト入力にも切替可)
5. **結果発表** — 達成度◎○△× / 良かった発言の引用 / 改善点1つ+言い換え例 / 100点スコアと称号

## 特徴

- **完全クライアントサイド**: サーバー・APIキー不要。部長AIはルールベース対話エンジン、採点はヒューリスティック自動採点
- **音声はブラウザ標準API**: 音声認識(SpeechRecognition/webkitSpeechRecognition) + 音声合成(speechSynthesis)。非対応環境・認識失敗時は自動的にテキスト入力へフォールバック
- **専門用語チェック**: DICOM・FPD・管電圧・遮蔽工事などを使うと部長が必ず「それは何ですか？」と聞き返す
- **値引き不可の縛り**: 値引きを口にすると「他社はもっと下げてくれる」「それなら他社にする」と揺さぶられる。値引きを断って価値(被ばく低減・処置時間短縮・安全性・実績・画質・AI・保守)で切り返すと「値段だけじゃないってことね」と前に進む
- **ゲーム性**: 100点スコア・称号・実施回数・連続日数・自己ベスト(localStorage)

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 全画面を持つシングルページ |
| `style.css` | スマホ縦画面ファーストのレスポンシブCSS |
| `js/data.js` | 商材・部長設定・シーン・モード・テーマ・セリフの全定義(**商材変更はここだけ**) |
| `js/engine.js` | 部長AI(対話エンジン)と自動採点 |
| `js/speech.js` | 音声認識・合成ラッパー(フォールバック付き) |
| `js/app.js` | 画面フロー・タイマー・チャットUI・記録 |

## 開発

ローカル確認: `python3 -m http.server` でこのディレクトリを配信してブラウザで開く。
エンジン単体は `node -e "$(cat js/data.js js/engine.js) …"` のように連結して
ブラウザなしでも確認できます。

再構築・拡張用のスキルを `.claude/skills/sales-roleplay-app/SKILL.md` に用意しています。
