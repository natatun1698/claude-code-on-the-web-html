### 4. 注記（定型5項。◯◯には検査室名を差し込み）
1. 上記の発熱量は平均的使用状態の値です。使用状況により増減します。
2. 上記の発熱量には、人から発生する熱量は含んでおりません。空調設備の設計においては、室内に入る人数を考慮して下さい。
3. ◯◯の空調機器は、必ず上記の空調条件を終日満足するように運転させて下さい。
4. ◯◯の温度勾配が2.7℃/hr以下になるようにしてください。
5. 空調機から吹き出す風が直接機器に当たらないような空調機レイアウトを検討してください。

### 5. 施工範囲・免責（定型文言）
- 島津製作所担当施工範囲
  - (1) 装置一式の搬入据付工事及び調整
  - (2) 装置一式の機器相互間の配線、接続及び利用者設備との接続工事
  - 「上記の島津製作所担当施工範囲以外は全て施主（御得意様）側設備工事となります。」
- 免責: 「この図面は配置案図です。建築設備等の確認及び機器搬入については、別途打合せが必要です。」
  （検討案図の場合は「この図面は検討案図です。…」）

### 連動ルール（テンプレートエンジンで自動処理）
- 部屋名は「図面内ラベル」「環境条件表の部屋名」「注記3・4の◯◯」「図面名称」の4箇所に連動
- 構成表の No. と平面図のバルーン番号は1対1対応（オプション追加時は自動採番）
- 縮尺は部屋サイズから自動選択（A3の図面エリアに収まる 1/30 → 1/50 の順）
