# 🐈 ラガマフィンとさんすう（弥花ちゃんせんよう）

小学5年生の弥花さんのための算数復習アプリ。ラガマフィン（猫）のキャラクターが
ずっと隣で伴走し、正解すると名前を呼んでほめてくれます。

- HTML / CSS / JavaScript のみ・ビルド不要。`index.html` をブラウザで開けば動きます。
- 外部通信なし（完全オフライン）。進捗は端末の localStorage にのみ保存されます。
- 猫のイラストは画像ファイルではなく、インラインSVG＋CSSアニメーションで描いています。

## モード
| モード | 内容 |
|---|---|
| 🐾 にがて克服モード | まちがえた問題(重み5)・無回答(重み4)・正解(重み1)の重み付きランダムで10問 |
| 📚 順ばんモード | 大問1〜8を通しで全問 |
| 🔁 もう一回チャレンジ | このアプリ内でまちがえた問題だけ |

セッション中にまちがえた問題は、最後に「リベンジタイム」としてもう一度だけ出題します。

※大問2(4)（二等辺三角形の底角）は、図に埋め込まれた数値が読み取れず解説を確定できないため、出題から除外しています（全29問）。

## 採点仕様
整数／小数／分数（`1/4`・`2/8`・`0.25`・帯分数どれでも可）に対応。全角数字、前後の空白、
`cm` `本` `枚` `円` `度` `通り` などの単位は自動で吸収して数値部分だけを比べます。

## ゲーム要素
ポイント／コンボ演出（3連続以上でキラキラ）／ポイントによるラガマフィンの成長（リボン→帽子→毛づや）／
分野別がんばり度バー＆バッジ（5問以上かつ正答率70%以上）／スタンプカード。

得点・偏差値・志望校判定など成績表の数値はアプリ内に一切表示しません。使っているのは
正誤（○×―）・全体正答率・思考スキルタグという学習用データのみです。
