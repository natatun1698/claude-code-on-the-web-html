# 病院放射線機器調査 → Excel作成スキル

引数 `$ARGUMENTS` で指定された地域（未指定なら依頼文から地域を特定。どちらにもなければユーザーに確認）の病院公式ホームページを調査し、放射線機器の一覧Excelを作成する。

## 対象機器（5分類）

CT・MRI・マンモグラフィ・骨密度・核医学・放射線治療装置は**除外**する。

1. 一般撮影（レントゲン）
2. 透視撮影台（X線テレビ）
3. CVS（アンギオ、血管撮影）— ハイブリッド手術室・心臓カテーテル装置を含む
4. 可搬型Cアーム（外科用イメージ）
5. 回診装置（ポータブルX線）

## 手順

### 1. 病院リストアップ

WebSearchで「{地域} 病院 放射線科 装置」「{地域} 病院 一覧」等を検索し、対象地域の病院（クリニック・診療所は除く）を列挙する。精神科・リハビリ専門病院も一般撮影装置を掲載していることがあるため含める。

### 2. 並行調査（エージェントのファンアウト）

病院を2〜4グループに分け、`general-purpose` エージェントを `run_in_background: true` で並行起動する。各エージェントへの指示に含めること:

- 対象機器5分類の明示（除外機器も明示）
- 取得項目: 病院名 / 機器分類 / メーカー名 / 型名 / 導入年月 / 参照URL / 装置写真のimg URL
- **メーカー名・型名が明記されていない場合は「記載なし」とし、推測で埋めない**
- 「放射線科」だけでなく「放射線室」「放射線部」「設備紹介」「機器紹介」等のサブページや `site:` 検索も探すこと
- 結果は装置ごとに1行（病院名 | 分類 | メーカー | 型名 | 導入年月 | URL | 写真URL）で報告

### 3. ネットワーク制限への対処

このリモート実行環境では病院サイトへの直接アクセス（WebFetch/curl）が403で遮断されることが多い。その場合:

- まずWebSearchの検索結果スニペットから情報収集する（エージェントは自然にこうする）
- 写真の取得やHTML検証が必要な場合のフォールバック: **ユーザーのリポジトリにGitHub Actionsの取得中継ワークフローを一時設置する**方法がある。ただし mainブランチを変更するため、**事前にユーザーへ確認するか、少なくとも作業後に必ず原状回復する**こと:
  1. `request/urls.txt`（URL一覧）+ `request/batch.txt`（バッチ名）+ `fetch.py`（urllib.requestでUA/Referer付き取得し `out/{batch}/NNN.html` に保存、INDEX.txt生成）+ push トリガーのワークフロー（取得結果を `results-{batch}` ブランチにpush）を main に置く
  2. ローカルから `git fetch origin results-{batch}` をポーリングして結果を取得
  3. **終了後は main からワークフロー一式を削除して原状回復し、results-* ブランチの削除を試みる**（この環境ではブランチ削除pushが403になることがある。その場合はユーザーに手動削除を案内）
- 画像が403になる場合はRefererヘッダー付きで再試行。それでも失敗したらExcelには写真URLのテキストのみ記載

### 4. 写真と装置の対応検証

ページのimgタグにalt属性がない場合、**生HTMLで見出し（装置名）と img の出現位置を突き合わせて対応を検証**する:

```python
import re
events = []
for m in re.finditer(r'(一般X線撮影装置|X線TV撮影装置|血管撮影装置|...)', html):
    events.append((m.start(), 'H: ' + m.group(1)))
for m in re.finditer(r'<img[^>]+src="([^"]+)"', html):
    events.append((m.start(), 'IMG: ' + m.group(1)))
for pos, e in sorted(events): print(pos, e)
```

対応が確認できない写真は使わない（誤った装置の写真を載せない）。

### 5. Excel作成

`pip install openpyxl pillow`（未導入なら）。シート構成:

1. **放射線機器一覧**: 列 = No. / 病院名 / 機器分類 / メーカー名 / 型名 / 導入年月 / 参照したURL（ハイパーリンク） / 装置の写真（埋め込み） / 備考
   - 写真はPILで `thumbnail((220, 160))` に縮小してから `openpyxl.drawing.image.Image` でセルにアンカー、行高は `画像高さ * 0.75 + 8`
   - ヘッダーは塗りつぶし＋白太字、全セル罫線＋折り返し、`freeze_panes = "A2"`
   - 「記載なし」と注記（「今年度更新と記載」等）を区別して書く
2. **掲載なしの調査済み病院**: 病院名 / 確認結果 / 確認したURL
3. **調査メモ**: 調査日・対象・注記（「記載なし＝公式HPに記載がないことを示す。推測補完なし」等）

ファイル名: `{地域}病院_放射線機器一覧.xlsx`

### 6. 納品

1. 作業ブランチにコミット＆push（コミットメッセージは日本語でよい）
2. `SendUserFile` でExcelをユーザーに送付
3. 報告には以下を含める: 装置件数・写真埋め込み数、機種名まで判明した病院、ネットワーク制限などの注意点、参照元URL一覧

## 知見（前回調査より）

- 病院公式HPでメーカー名・型名まで掲載している例は少数派。「FPD方式」「最新機種に更新」程度の記述が大半なので、「記載なし」が多くても正常
- 可搬型Cアームを公式HPに掲載する病院はまれ（手術室設備は非公開が多い）
- 病院の名称変更・移転に注意（検索結果の旧名称と公式サイトの現名称を突き合わせる）
- Wixサイト（static.wixstatic.com）の画像はaltに装置名が入っていることが多く、`~mv2.jpg` の素URLで原寸が取れる
