# 問題データのスキーマ

ファイル: `neko-sansu/data/problems-{年度}-{回}.json`(1つの試験につき1ファイル、**JSON配列**)。
読み込む一覧: `neko-sansu/data/index.json` → `{ "files": ["problems-2025-1.json", ...] }`。
図: `neko-sansu/data/figures/{id}.svg`(複数の小問で共有する図は `figures/{年度}-{回}-{大問}.svg`)。

## 1問の項目
| 項目 | 必須 | 形 |
|---|---|---|
| `id` | ◯ | `"年度-回-大問-小問"`(例 `"2025-1-2-3"`)。全ファイルを通して一意 |
| `source` | ◯ | `{ "year": 2025, "round": 1, "big": 2, "no": 3 }`(数値。`id` と一致させる) |
| `tags` | ◯ | 分野の配列。下の一覧の文字列を**そのまま**使う。先頭が主分野(正答率の集計に使う) |
| `pattern` | ◯ | 解法パターン名(「もう一問」の検索キー)。例 `"つるかめ算(全部同じと考える)"`。同じ解き方には同じ文字列を使う |
| `text` | ◯ | 問題文。改行は `\n`。分数は `{{5/8}}`、帯分数は `{{2 1/13}}`(整数と分数の間は半角空白)。空らんは `□` |
| `figure` | 図があれば◯ | `"figures/2025-1-2-5.svg"`(`data/` からの相対パス) |
| `answerType` | ◯ | `int` / `dec` / `frac` / `unit` / `time` / `multi` / `ordered` / `choice` |
| `answer` | ◯ | 下の「型ごとの書き方」 |
| `unit` | 任意 | 答えの単位(表示・読み上げ用)。例 `"cm²"` `"円"` `"秒後"`。採点には使わない(単位なしで数だけ入力する) |
| `essence` | ◯ | 本質的に何を聞いているか。小5向けの言葉で1〜2文 |
| `hint1` / `hint2` | ◯ | 段階ヒント(`explanation-style.md`) |
| `exp` | ◯ | 解説。公式解説の丸写し禁止、小5向けに書き直す |
| `realworld` | 任意 | 社会で役立つ場面。1文。無理に書かない |
| `dependsOn` | 任意 | 前の小問の答えを問題文に書き足して単独で解けるようにしたとき、元の小問の `id` |
| `status` | ◯ | `"ready"`(出題する) または `"excluded"`(出題しない) |
| `reason` | `excluded` なら◯ | 除外した理由(例「公式解答が読み取れない」「図が複雑で描き切れない」) |

`excluded` の問題は `answer` `hint1` `hint2` `exp` `essence` が空文字や `"(未作成)"` でもよい。`id` `source` `tags` `text` `status` `reason` は必要。

## 型ごとの `answer` の書き方
| `answerType` | `answer` の形 | 例 | 入力のしかた |
|---|---|---|---|
| `int` | 整数の文字列 | `"26"` | 数字キー |
| `dec` | 小数の文字列 | `"7.74"` | 数字キー(`.`) |
| `frac` | `"分子/分母"` または `"整数 分子/分母"`(既約でなくても可、採点は値で比べる) | `"7/8"` `"2 1/13"` | `/` と `と` キー(`2と1/13`) |
| `unit` | 数の文字列 + `unit` 必須 | `"150"` + `"unit": "cm"` | 数字キー。単位は画面に表示される |
| `time` | `{ "hours": 1, "minutes": 21, "seconds": 0 }`(0 の項目は省略可) | `{ "hours": 1, "minutes": 21 }` | 時間キー(`1時間21分`) |
| `multi` | 文字列の配列。`"orderMatters": false`(順不同) か `true`(`"labels": ["ア","イ"]` の順に答える) | `["3.1","3.6"]` | `,` で区切る(`3.1,3.6`) |
| `ordered` | `choices` の要素を正しい順に並べた配列。`"choices": ["A","B","C","D"]` 必須 | `["A","B","D","C"]` | 選択肢ボタンをタップして並べる |
| `choice` | `choices` の中の正解の文字列。`"choices": [...]` 必須 | `"イ"` | 選択肢ボタンを1つタップ |

数値はすべて**文字列**で書く(`"26"`。`26` は不可)。負の数は `"-3"`。

## 分野(`tags`)の一覧 — この文字列をそのまま使う
```
計算/四則計算・逆算  計算/計算のくふう  計算/単位の計算
和と差/和差算  和と差/分配算  和と差/消去算  和と差/つるかめ算  和と差/平均とのべ  和と差/過不足算
割合と比/割合と比  割合と比/還元算・相当算  割合と比/倍数算  割合と比/売買損益  割合と比/濃度  割合と比/仕事算
速さ/速さと比  速さ/旅人算  速さ/通過算
図形/角度・面積・長さ  図形/辺の比と面積の比  図形/体積・表面積  図形/展開図  図形/図形上の点の移動
表とグラフ
数の性質/約数と倍数  数の性質/整数・小数・分数の性質
規則性/数列  規則性/周期算  規則性/植木算
場合の数  調べ・推理
```
一覧にない分野名は `tests/data.test.js` で FAIL になる。どうしても必要なら、一覧(`neko-sansu/problems.js` の `TAGS`)とこのファイルの両方に足す。

## 出題の重み(参考)
`problems.js` は主分野ごとに重みを持つ(四則計算・逆算が最多、次に角度・面積・長さ、割合と比)。
データ側で重みを書く必要はない。間違えた問題は翌日以降に優先して再出題される。

## 完全な1問の例
```json
{
  "id": "2025-1-2-5",
  "source": { "year": 2025, "round": 1, "big": 2, "no": 5 },
  "tags": ["図形/角度・面積・長さ"],
  "pattern": "円と正方形の面積(差を求める)",
  "figure": "figures/2025-1-2-5.svg",
  "text": "図は、1辺6cmの正方形の内側に、円がぴったり入ったものです。図の斜線部分の面積は何cm²ですか。ただし、円周率は3.14とします。",
  "answerType": "dec",
  "answer": "7.74",
  "unit": "cm²",
  "essence": "求めにくい形(四すみの部分)を、「正方形 − 円」のように、求めやすい図形の差として考えられるかを聞いています。",
  "hint1": "斜線部分の面積は、正方形の面積から円の面積をひけば求められます。",
  "hint2": "円は正方形にぴったり入っているので、円の直径は6cm、半径は3cmです。円の面積は 3 × 3 × 3.14 です。",
  "exp": "正方形の面積は 6 × 6 = 36(cm²)。円の半径は 6 ÷ 2 = 3(cm)なので、円の面積は 3 × 3 × 3.14 = 28.26(cm²)。斜線部分は 36 − 28.26 = 7.74(cm²)。",
  "status": "ready"
}
```
