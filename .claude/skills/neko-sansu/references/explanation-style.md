# 解説・ヒント・猫のセリフの書き方

## 読み手
小学5年生。漢字は小5までに習うものだけ。それ以外はひらがな(例: 濃度→「のうど」、損益→「もうけ・そん」)。
データの `essence` `hint1` `hint2` `exp` `realworld` は**です・ます調**で書く(猫の「〜にゃ」は `app.js` の
セリフ側で付けるので、データには書かない)。`tags` `pattern` は大人向けの正式名でよい。

## 丸写しの禁止
公式解説・市販解説の文をそのまま、または語尾だけ変えて書かない。**要点を自分の言葉で、小5向けに書き直す**。
手順: (1) 公式解説を読んで式の流れを理解する → (2) 閉じる → (3) 「なぜその式になるか」を1手ずつ、子どもに話すつもりで書く。

## 5項目の役割
| 項目 | 役割 | 書き方 |
|---|---|---|
| `essence` | この問題は本質的に何を聞いているか | 1〜2文。「〜できるかを聞いています。」の形。解法名ではなく**考え方**を書く(例「求めにくい形を、求めやすい図形の差として考えられるか」) |
| `hint1` | 方向づけ | 答えに近づく数値は出さない。「どこに注目するか」「何を先に計算するか」だけ |
| `hint2` | 1手目を具体的に | 最初の計算を1つだけ示す(途中の値は出してよい)。答えは出さない。最後は「〜でしょう?」「〜してみましょう」で子どもに渡す |
| `exp` | 解説 | 式→計算→答えの順。1つの式ごとに「。」で区切る。単位は `(cm²)` のように式の後ろ。最後の値が答え |
| `realworld` | 社会で役立つ場面 | 任意。1文。買い物・料理・時間・地図など身近な場面。思いつかなければ書かない |

### 悪い例 → 良い例
- hint1「答えは 15 です」 → 「最後の計算は、かけ算ですか、わり算ですか。そこを見ましょう。」
- exp「公式より 15」 → 「12 × □ ÷ 2 = 90 なので、12 × □ = 180。□ = 180 ÷ 12 = 15(cm)。面積の式を逆にたどりました。」
- essence「つるかめ算の問題」 → 「全部を片方だと考えて、実際との差から、もう片方の数を求められるかを聞いています。」

## 猫(スコティッシュフォールド)のセリフ(`app.js` 側)
- 語尾は「〜にゃ」「〜かにゃ?」。命令形は使わず「〜してみるにゃ」。
- 出題直後: 「紙に 書いてみてにゃ」。正解: 結果ではなく**プロセス**をほめる(「式の 立て方が バッチリにゃ」「比を そろえたのが えらいにゃ」)。
- 不正解: 「おしい! もう一回 紙に 書いてみるにゃ」→ ヒント1 → ヒント2 → 解説。すぐ答えを出さない。
- 離脱を責めない。再開時: 「おかえりにゃ。さっきの つづきから やる?」
- ずかん画面: 「スコティッシュフォールドは、耳が 前に おれているのが とくちょうの ねこにゃ。おだやかで 人なつっこいにゃ。『スコずわり』という すわり方も 有名にゃ」程度。
- `cat.js` の mood: `idle` / `think`(出題中) / `happy` / `cheer`(はげまし) / `sleep`(タイトル待機)。
