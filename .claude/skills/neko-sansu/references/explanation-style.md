# 解説・ヒント・猫のセリフの書き方

## 読み手
小学5年生。漢字は小5までに習うものだけ。それ以外はひらがなにする
(例: 濃度→「のうど」、損益→「そんえき」は画面では「もうけ」「そん」)。
分野タグ(`tags`)は大人向けの正式名でよいが、画面に出す `title` はやさしく書く。

## 6 項目の役割
| 項目 | 役割 | 書き方 |
|---|---|---|
| `essence` | この問題は本質的に何を聞いているか | 1文。「〜を もとめる問題にゃ」「〜が 同じであることを つかう問題にゃ」 |
| `pattern` | 解法パターン名 | 名詞。保護者が見ても分かる正式名(例: つるかめ算) |
| `hint1` | 方向づけ | 答えに近づく数値は出さない。「どこに注目するか」だけ |
| `hint2` | 1手目を具体的に | 最初の計算を 1 つだけ示す。答えは出さない |
| `exp` | 解説 | 式→計算→答えの順。1行1式。答えは `<b>` で太字。最後に「本質の一言」を再掲 |
| `realworld` | 社会で役立つ場面 | 任意。1文。買い物・料理・時間の計算など身近なもの |

### 悪い例 → 良い例
- hint1「答えは 15 だにゃ」 → 「さいごの計算は かけ算? わり算? そこを見るにゃ」
- exp「計算すると 15」 → 「12×□÷2 = 90 → 12×□ = 180 → □ = 180÷12 = <b>15</b>cm。面積の式を ぎゃくに たどったにゃ」

## ほめ方(正解時)
- 結果ではなく**プロセス**をほめる。テンプレートごとに `explain().pattern` を使って
  「<pattern>の式の立て方が バッチリにゃ」と自動生成する。固定の褒め言葉は `app.js` の `PRAISE` に追加する。
- 連続正解でキラキラ演出(既存 `sparkle()` を流用)。

## 不正解時の流れ
1. 「おしい!」+「紙に ちょっと書いてみるにゃ」→ もう一度入力できる(やり直し回数を記録)
2. 2回目も不正解 → ヒント1 ボタン表示
3. ヒント1 → ヒント2 → 解説 の順にボタンで開く。飛ばして解説は見られない。
4. 解説のあと「もう一問 やってみる?」で同じテンプレートの別 seed を出す。

## 猫(スコティッシュフォールド)のセリフ
- 語尾は「〜にゃ」「〜にゃ〜」「〜かにゃ?」。命令形は使わず「〜してみるにゃ」。
- 離脱(途中でやめた)を責めない。再開時は「おかえりにゃ。さっきの つづきから やる?」。
- ずかん画面の紹介文: 「スコティッシュフォールドは、耳が 前に おれているのが とくちょうの ねこにゃ。
  おだやかで 人なつっこいにゃ。『スコずわり』という すわり方も 有名にゃ」程度。
- `cat.js` の mood: `idle` / `think`(出題中) / `happy` / `cheer`(はげまし) / `sleep`(タイトル待機)。
