# 著作権方針(必ず守る)

## 結論
- **リポジトリに入れてよいもの**: 自分で考えたオリジナルの類題テンプレート、オリジナルの図、オリジナルの解説。
- **絶対に入れないもの**: 入試過去問・模試・市販問題集・塾教材の問題文、図、数値の並び、解説。言い換え・数値だけ変えたものも含む。

## 理由
このリポジトリは公開されている。過去問は学校・出版社に著作権があり、公開配布は許されない。
家庭内で使うこと自体は問題ないので、原題は**端末の中にだけ**置く(取り込み機能)。

## 「類題」として許される作り方
1. 原題から**解法パターン**(例: 「食塩水を混ぜて濃度を求める」)だけを抜き出す。
2. 場面・登場するもの・数値の決め方・文章を**自分の言葉で**書き直す。
3. 数値は `params(rng)` でランダムに決める。固定の数値を 1 組だけ書かない。
4. 書き上げたら原題と並べて、**文が似ていないこと**を確認する。似ていたら書き直す。

## 機械チェック(`tests/copyright.test.js`)
- `neko-sansu/` 配下の `.js` `.html` `.md` を走査し、次を検出したら FAIL:
  - 学校名・入試名・年度+「入試」「過去問」「第○回」などの語(禁止語リストは `tests/forbidden-words.js`)。
  - テンプレートの `text` が 1 組の固定数値しか出さない(= 原題そのものの疑い)。
- 禁止語リストは短く保ち、見つけたら語を足す。

## 原題JSON の扱い
- ファイル名の例: `genda-2024.json`。リポジトリの `.gitignore` に `neko-sansu/**/*.json` を入れ、誤コミットを防ぐ。
- README には「このアプリは過去問を含まない。原題は各自が用意して端末内に取り込む」と書く。
- 履歴には問題 ID だけを残す(本文を保存しない)。バックアップファイルにも本文を含めない。
