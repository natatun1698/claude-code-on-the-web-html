# 設置施設名簿PDFの年次比較Excel作成

スキャン(画像)PDFの施設名簿から対象地域の施設・装置を書き起こし、
年次比較のExcel(変更箇所に色付き)を作成して `SendUserFile` で納品する。

## 全体の流れ

1. 環境準備(poppler-utils / pillow / numpy / openpyxl)
2. テキスト抽出を試す → 空ならスキャンPDFなので画像レンダリングに切り替え
3. ページ全体ビューで対象都道府県のセクションを一括読み取り
4. 曖昧な箇所・差分が疑われる箇所を拡大クロップで個別検証
5. 比較データを組み立て、Excelを生成、`SendUserFile` で送付

**重要:作業ファイルはすべてスクラッチパッドディレクトリに置く。リポジトリを汚さない。**

## 1. 環境準備

```bash
sudo apt-get install -y poppler-utils || { sudo apt-get update -qq; sudo apt-get install -y poppler-utils; }
pip install -q pillow numpy openpyxl
```

- `apt-get install` が 404 で失敗したら `apt-get update` してから再実行(ミラーのバージョンずれ)。

## 2. テキスト抽出を試す

```bash
pdftotext -layout input.pdf out.txt && wc -l out.txt
```

- 出力が0行 → テキスト層なし(スキャンPDF)。以降は画像として読む。
- テキストが取れた場合はそのまま解析してよいが、レイアウト崩れに注意。

## 3. ページ全体ビューで読み取る(最重要ノウハウ)

Read ツールでPDFページを直接読むと、見開きスキャンでは縮小されすぎて判読できない。
次の手順が確実:

1. `pdftoppm -r 300 -png` でページをPNG化する。
2. 見開き(2ページ/1画像)なら **左右のページ半分ずつに切り出す**。
3. ページ半分を **幅約1,300〜1,500px に縮小**(300dpiの0.75〜0.85倍)して保存し、
   Read ツールで読む。この解像度なら名簿の細かい活字でもほぼ判読できる。
4. **細い縦罫線からの列切り出しは最初はやらない。** 罫線検出はノイズが多く、
   列の切れ目がずれて機種名が途切れる。まずページ全体ビューで読み、
   足りない箇所だけ後で拡大する。

```python
from PIL import Image
im = Image.open('page-01.png')          # 300dpi レンダリング済み
half = im.crop((1660, 250, 3508, 2480)) # 見開きの右ページ部分(要調整)
half = half.resize((int(half.width*0.75), int(half.height*0.75)), Image.LANCZOS)
half.save('view_right.png')             # → Read で読む
```

### 名簿の読み方(『新医療』設置施設名簿の場合)

- 都道府県セクションは `◆ 北海道` のような見出しで始まる。対象セクションの
  開始ページ〜次セクション見出しまでを読む。
- 1施設に複数行(複数装置)がぶら下がる。行は「メーカー略号・機器タイプ○文字・
  システム名・プレーン記号・オプション」の形式。
- **エントリは列末・ページ末で途切れて次の列/ページ先頭に続く。**
  列の先頭に施設名のない行があれば直前の施設の続き。
- 社名略号: `フ`=フィリップス・ジャパン, `キ`=キヤノンメディカルシステムズ,
  `シ`=シーメンスヘルスケア, `G`=GEヘルスケア・ジャパン, `島`=島津製作所,
  `F`=富士フイルムヘルスケア(年版により有無あり)
- 機器タイプ(丸囲み文字): ©=心血管, Ⓝ=脳血管, Ⓖ=腹部血管, Ⓤ=全身血管
- プレーンタイプ: [S]=シングル, [B]=バイ, [D]=デュアル
- オプション: ICT(IVR-CT), DSA, シネ, 3D, CD, Net
- 施設名「その他」= 名称の掲載を希望しない施設。1行として扱う。

## 4. 拡大検証(差分は必ずズームで確認)

年次間で差分が疑われる箇所、判読が曖昧な箇所は、**該当部分を2〜3倍に拡大した
クロップを作って Read で再確認**してから確定する。全体ビューの読み間違いを
そのまま差分として報告しない。

```python
c = im.crop((x0, y0, x1, y1))
c = c.resize((c.width*3, c.height*3), Image.LANCZOS)
c.save('zoom_check.png')  # → Read で確認
```

特に注意する点:
- `INFX-8000C / 8000V / 8000H` などの1文字違い
- `Azurion 7M / 7 M20 / 7 M12 / 7 B12 / 7 B20` の型番
- 施設名の改称(例: 旧名称が消え、同一機種の新名称施設が現れる)
  → 同一施設の可能性を備考に書く。装置入替と混同しない。

## 5. 比較の分類ルール

施設名をキーに両年を突き合わせ、次の4区分に分類する:

| 区分 | 条件 | 色 |
|------|------|----|
| 変更 | 装置の入替・増設・減少(メーカー/システム名/台数の変化) | 黄 `FFE699` |
| 新規 | 新しい年版で新規掲載 | 緑 `C6E0B4` |
| 掲載なし | 新しい年版に掲載がない | 赤 `F4B8B8` |
| (無印) | 変更なし | なし |

- **機器タイプの丸囲み文字(©/Ⓤ等)だけの違いは変更扱いしない**(誌面の揺れが多い)。
- プレーン記号だけの違い([S]→[B])は色を付けず備考に記載。
- オプション文字列(シネ,DSA等)の違いは無視してよい(Excelにも載せない)。
- 型番の表記ゆれ(例: `Azurion 7M`→`Azurion 7 M20`)は変更として色を付けつつ
  「表記修正の可能性あり」と備考に書く。
- 施設名の表記変更のみで装置が同一なら色なし+備考。

## 6. Excel 生成

`scripts/build_excel.py` を使う。データ(施設名・年ごとの装置リスト・区分・備考)を
Pythonリストとして書き、`build_workbook()` に渡すだけでよい。

仕様:
- 列: No. / 施設名 / 旧年版(メーカー・システム名) / 新年版(メーカー・システム名) / 変更区分 / 備考
- 年版ヘッダーは2列結合の2段ヘッダー。「○○年版(○年3月1日現在)」のように基準日を書く
- 複数装置は1セル内改行(1行=1台)。メーカー列とシステム名列の行を対応させる
- システム名にはプレーン記号を付ける(例: `INFX-8000C [S]`)
- 掲載なしの年は `―` / `(掲載なし)`
- シート上部にタイトル・出典・色の凡例、ヘッダー下で `freeze_panes`
- 該当行の施設名〜備考セルに区分色を塗る

生成後、`SendUserFile`(display: attach)で納品する。

## 7. 納品時の報告

- 施設数、色付けの凡例、区分ごとの件数
- 「入替」が明確な施設のリスト(旧→新機種)
- 読み取り上の注意(オプション省略、改称の可能性がある施設など)
