# Slack デイリーまとめ

`config.json` に登録された Slack チャンネルの直近メッセージを取得し、日本語の要約レポートを作成するスキル。

## 前提条件

各ワークスペースの Slack トークンが環境変数に設定されていること:

| ワークスペース | 環境変数 |
|---|---|
| T05FDPJRQBD | `SLACK_TOKEN_T05FDPJRQBD` |
| TBJRY8G6S | `SLACK_TOKEN_TBJRY8G6S` |

トークンは User token (`xoxp-...`) または Bot token (`xoxb-...`)。必要スコープは
`channels:history`, `channels:read`, `users:read`（プライベートチャンネルなら
`groups:history`, `groups:read` も）。Bot token の場合は対象チャンネルに Bot を
招待しておくこと。トークンが未設定の場合はスクリプトがエラーを表示するので、
その内容をユーザーに伝えて設定を案内する。

## 手順

1. メッセージを取得する:

   ```bash
   python3 .claude/skills/slack-daily-summary/scripts/fetch_messages.py
   ```

   期間を変えたい場合（例: 直近 48 時間）は `--hours 48` を付ける。

2. 出力されたトランスクリプトを読み、**チャンネルごと**に日本語でまとめる。
   構成は以下:

   - **📌 3行サマリ** — チャンネル全体の動きを最大3行で
   - **主なトピック** — 話題ごとに1〜3文。誰が何を提起し、どう展開したか
   - **決定事項** — 決まったこと。なければ省略
   - **要対応・依頼** — 誰かに対するお願い・未回答の質問・期限があるもの
   - **共有されたリンク・ファイル** — あれば箇条書き

3. 最後に両チャンネルを横断した **「今日のハイライト」** を2〜3行で書く。

## まとめ方の注意

- 時系列の逐語訳ではなく、話題単位で整理する。
- 発言者名は表示名をそのまま使う。
- メッセージが0件のチャンネルは「本日は投稿なし」と一言だけ書く。
- 雑談しかない日は無理に項目を埋めず、雰囲気を1〜2文で伝える。
- タイムスタンプは UTC で出力されるため、必要なら日本時間 (UTC+9) に直して書く。

## チャンネルの追加・変更

`config.json` の `channels` 配列にエントリを追加する。別ワークスペースの
チャンネルを追加する場合は、その ワークスペース用のトークン環境変数名を
`token_env` に指定する。
