# スキャン名簿PDFの年次差分 → Excel 化スキル

## 概要

雑誌の設置施設名簿(画像スキャン、見開き、1ページ4段組、
「病院名列+システム列」のペア構造)の新旧2版を比較し、
新版で追加されたシステム(=期間中に導入されたと推定)を抽出する。

処理は `scripts/` の実証済みパイプラインを使う。**ゼロから書き直さないこと。**
過去の実行で判明した落とし穴が全てスクリプトに織り込まれている。

## 前提セットアップ

```bash
sudo apt-get update && sudo apt-get install -y poppler-utils tesseract-ocr tesseract-ocr-jpn
pip install pillow numpy rapidfuzz openpyxl
```

PaddleOCR等のDLモデルはプロキシ遮断で使えない環境がある。tesseractで動く設計。

## パイプライン(順番に実行)

作業ディレクトリにこのスキルの `scripts/*.py` をコピーして進める。

### 1. PDF調査(必ず最初に)

- `pdfinfo` でページ数・サイズ確認。`pdftotext -layout` を試し、テキスト層が
  あればOCR不要の簡易パスも検討(通常は画像スキャンで空)。
- `pdftoppm -r 600 -gray -png`(A4見開きスキャン)/ `-r 500`(A3撮影)で全ページ描画。
- **各PDFの数ページを Read で目視**して以下を確認する:
  - 誌面ページ番号(フッター `(121) 新医療 …`)と**ページ順序**
    (スキャンPDFはページ順が入れ替わっていることがある。読み順は誌面番号の降順)
  - **収録範囲**(Part1=北海道〜神奈川、Part2=新潟以降など。
    旧版がPart1+2合本、新版がPart1のみ等のケースあり → 比較範囲は共通部分のみ)
  - 基準日(「YYYY年3月1日現在」)→ 導入年推定の根拠

### 2. セグメンテーション+OCR (`extract.py` + `extract2.py` + `extract3.py`)

`python3 extract3.py <spread.png> <outdir> <base>` を全ページに実行(バックグラウンド推奨、計30-60分)。

内部処理(いずれも実際に必要だった対策):
- 見開き分割: 撮影本はノドの影=最暗帯、フラットスキャンは最白帯で分割
- 傾き補正(±1.5°) + 段組は**バンド分割で境界検出→行毎に補間した曲線でマスク切り出し**
  (ページ湾曲・傾きがあるため、ページ全体の直線カットは必ず失敗する)
- ペア境界の判定は「左=密(システム列)/右=疎(病院名列)」の白ギャップ方向 + 細罫線
- OCRは2パス: システム列=jpn+eng 2倍拡大 / 病院名列=**jpn単独 3倍拡大**
  (jpn+engだと病院名がラテン文字のゴミになる)
- 県ヘッダーは網掛けバーを**画像として検出**(OCRでは読めない)

### 3. 構造化 (`parse.py`)

- ORDER_2024 / ORDER_2025 を実ページ構成に合わせて書き換える(手順1の目視結果)
- システム行の開始判定は機種ファミリ辞書とのファジー一致(`canon.py`)。
  メーカー記号(フ・キ・シ・G・島)はOCRで崩れるため記号だけに頼らない
- 病院名の折返し結合: 「システム開始行と縦位置が揃う名前行=新病院、揃わない=折返し」
- 県割当は網掛けバー順+OCR高信頼時のみシーケンス自己補正
- 出力 `records{year}.json` の県別病院数を両年で見比べ、大きなズレは異常

### 4. 差分 (`diff.py`)

- 県内で病院をファジー+出現順マッチング(OCR誤読名に頑健)
- 正規化機種名(canon.py)の集合差で「2025年版のみのシステム」=候補を出す

### 5. 目視検証(必須・省略禁止)

OCR差分には偽陽性が必ず混ざる(旧版側のOCR取りこぼし、機種番号の誤読B12/B20等)。
`verify_crops.py` で候補ごとに新旧両年の該当領域クロップのモンタージュを作り、
**Readで読んで1件ずつ確認**する。確認済みのみ `verified.json` に残す。
判断基準: 旧版の同病院欄にそのシステムが本当に無いか / 機種名は正しいか /
病院マッチング自体が正しいか。

### 6. Excel生成 (`make_excel.py`)

`python3 make_excel.py verified.json 出力.xlsx`
列: 都道府県 / 病院名 / メーカー名 / システム名 / 予想される導入年。
導入年は両版の基準日の間(例: 2024年3月〜2025年2月)。注記シートに方法と限界を書く。

## 重要な教訓

- 段組カットの失敗は「病院名と隣ペアのシステムの誤結合」として現れる。
  パース結果がおかしい時はまずセグメンテーション画像を目視する
- 県ヘッダー網掛けバーはtesseractではほぼ読めない。バー検出+順序で割り当てる
- 病院名OCRは2-3割崩れる前提で設計する(照合はファジー+出現順、最終確認は目視)
- 機種名はASCIIが多くOCRに強いが、Azurion↔Aanion等の崩れは canon.py の
  ファミリ辞書で吸収する。新しい機種名が出たら辞書に追加する
- 検証なしでExcelを出さないこと。OCRだけの差分は納品品質にならない
