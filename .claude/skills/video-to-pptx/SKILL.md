# video-to-pptx: 動画→スクショ多めのPowerPoint資料化

デモ動画(特にAIツールのプロンプト入力→出力のデモ)を、高解像度スクリーンショット中心の
PowerPointに変換するワークフロー。

## 手順

### 1. 環境準備
```bash
sudo apt-get update -qq && sudo apt-get install -y ffmpeg   # 未インストール時
pip install python-pptx -q
```
※ apt が 404 を返したら `apt-get update` してから再実行する。

### 2. 動画の確認とフレーム抽出
```bash
ffprobe -v error -show_entries format=duration -show_entries stream=width,height -of default=nw=1 "$VIDEO"
mkdir -p $SCRATCH/frames
ffmpeg -v error -i "$VIDEO" -vf fps=1/4 "$SCRATCH/frames/f_%03d.png"   # 4秒ごとに1枚
```
- 動画が長い(>10分)場合は fps=1/4〜1/6、短い場合は fps=1/2 に調整。
- フレームは動画のネイティブ解像度のまま保存する(縮小しない=高解像度スクショ)。

### 3. フレームの読解(2パス)
1. **粗く読む**: Readツールで4枚おき程度に読み、動画の章立て(デモの区切り)を把握する。
2. **細かく読む**: 重要な場面(プロンプト全文が映るフレーム、出力結果、モデル選択、
   データの説明など)の前後フレームを追加で読み、取りこぼしを埋める。
- プロンプト文は**一字一句そのまま**書き起こす(資料の核になる)。
- 各デモについて「入力データ → プロンプト → 実行中 → 出力」の流れでフレームを選定する。

### 4. PowerPoint生成(python-pptx)
構成テンプレート:
1. **タイトル**: 動画名・出典・本資料の目的
2. **全体構成(アジェンダ)**: 動画内のデモ一覧
3. **各デモごとに**:
   - プロンプト全文スライド(色付きボックスで強調、使用モデル・添付データを明記)
   - スクショスライド × 複数(入力データ → プロンプト入力画面 → 実行中 → 出力結果)
4. **まとめ**: プロンプトと出力の対応、活用のヒント

実装ルール:
- スライドは 16:9(13.333 × 7.5 インチ)。
- スクショは幅10インチ以上で大きく貼り、下に1行キャプション(グレー12pt)。
- 日本語フォントは "Meiryo UI" を明示的に指定する。
- 上部にカラーバー+白抜きタイトル(セクションごとに色分けすると見やすい)。
- 生成スクリプトはスクラッチパッドに置き、pptx はリポジトリの `docs/` に出力する。

### 5. 納品
- `SendUserFile` で pptx を送付(display: attach)。
- リポジトリ管理する場合は指定ブランチにコミット&プッシュする。

## 注意
- montage(ImageMagick)は環境にないことが多い。フレームはReadツールで直接読む。
- 動画がYouTube画面の録画である場合、冒頭にブラウザ枠付きフレームが混ざる。
  資料には全画面化後のフレームを優先して使い、ブラウザ枠付きは文脈説明用に限定する。
- スクショに人物や個人情報が映る場合は、必要最小限のフレームだけを採用する。
