# 🐈 ラガマフィンとさんすう ― マンスリーテスト10月号(算数5)

キャンパス マンスリーテスト「算数5 10月号」(5後期)の復習アプリ。
`/sansu-mihana/` と同じ作り(猫キャラ伴走・苦手優先出題・完全オフライン)で、問題だけをこのテストに差し替えています。

- HTML / CSS / JavaScript のみ・ビルド不要。`index.html` をブラウザで開けば動きます。
- 外部通信なし。進捗は localStorage(キー `sansu-monthly10-v1`)にのみ保存。
- 得点・偏差値・順位は表示しません。まちがえたときは💡と解説でやさしくフォローします。

## 収録問題(全14問)
| 大問 | 内容 | 分野 |
|---|---|---|
| 1 (1)〜(2) | 計算(÷×・分数の四則) | 🧮 計算 |
| 1 (3)〜(5) | 簡単な整数の比 | ⚖️ 比 |
| 2 (1)〜(4) | 比の分配・連比 | ⚖️ 比 |
| 2 (5) | 分母と分子の和が一定の分数 | 📖 文章題 |
| 2 (6)〜(7) | 重さと体積(比例)・表(反比例) | 📈 比例・反比例 |
| 3 (1)〜(2) | 年れい算 | 📖 文章題 |

## モード
- 🐾 にがて克服モード … 10問。このテストは採点前なので全問同じ重み。アプリ内でまちがえた問題が自動で重くなります。
- 📚 順ばんモード … 14問を大問順に。
- 🔁 もう一回チャレンジ … アプリ内でまちがえた問題だけ。

最後に「リベンジタイム」でまちがえた問題をもう一度だけ出題します。

## 採点仕様
- 整数・小数・分数(`41/6`・`6と5/6`・`6 5/6` いずれも可)、単位(円・才・年後・cm³ など)は自動で吸収。
- 比は `7:6` / `7：6` の形(最も簡単な比と完全一致)。
- 大問2(5)「はじめの分数」だけは約分前(`58/62` など)を不正解にしています。
