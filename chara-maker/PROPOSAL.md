# 「そっくりメーカー」提案書
AIキャラクター作成アプリ ― 企画・UX・実装方針

---

## 1. アプリのコンセプト・ターゲットユーザー像

**コンセプト**
- 「あの人そっくり」を、パーツの掛け合わせと微調整でつくる似顔絵キャラメーカー
- ともだちコレクション(Nintendo Switch)の「パーツが足りない・微調整できない」不満を解消
- ログイン不要・インストール不要。URLを開けば即プレイ(GitHub Pagesの静的Webアプリ)

**ターゲットユーザー**
- Miiやともコレで「似てるけど、あと一歩」の物足りなさを感じた小中学生〜大人
- 家族・友達・先生など身近な人を何体も作って集めたい人
- 推しや有名人「風」のキャラを作って楽しみたい人
- 端末を選ばない(PC/タブレット/スマホのブラウザで動作)

## 2. 主要機能一覧

| 機能 | 内容 |
|---|---|
| パーツ選択UI | 12カテゴリ。輪郭60/肌色56/髪型60/髪色56/目56/瞳色56/眉50/鼻50/口60/耳50/服装60/小物57 = **合計671種類** |
| 微調整スライダー | パーツはそのままで「肌の濃さだけ」「目の間隔だけ」等を±調整(輪郭幅・肌濃度・髪明度・目の間隔/高さ/角度・眉/鼻/口の位置・口幅・耳サイズ) |
| コレクション | 名前を付けて保存、一覧表示、再編集、削除。localStorageで端末に永続化 |
| JSON入出力 | コレクション全体の書き出し/読み込み → 友達との交換・機種変更時の引っ越しに対応 |
| PNG書き出し | 完成キャラを640×720のPNG画像でダウンロード |
| AIサジェスト(β) | 写真から肌の色・髪の色・髪型候補を推定して自動適用。**画像は端末内でのみ処理し、送信・保存しない** |
| おまかせ生成 | ワンタップでランダム生成 → そこから直す、という作り方も可能 |

## 3. 既存アプリ(ともだちコレクション等)との差別化

| 観点 | ともコレ/Mii | そっくりメーカー |
|---|---|---|
| パーツ数 | 各カテゴリ十数種 | **各カテゴリ50種以上(計671種)** |
| 微調整 | パーツ交換のみ | パーツ固定のまま色味・位置・角度をスライダーで連続調整 |
| 起動 | 本体+ソフト必要 | URLだけ。ログイン不要 |
| 写真からの作成 | なし(Miiは一部あり) | 写真から肌・髪の色/髪型候補をAIサジェスト |
| 共有 | 本体内/QR | JSON書き出しで誰とでも交換、PNGでSNS共有 |

- 「輪郭はそのまま肌だけ濃く」= 肌スウォッチ56色 × 濃さスライダーで実現(本アプリの核となる思想:**選ぶ→微調整の2段階**)

## 4. パーツ選択UIのUXアイデア(50種以上をどう見せるか)

- **カテゴリタブ×番号付きグリッド**: ①輪郭→⑫小物の順に迷わず進める作成フロー
- **「今の顔」プレビュー付きサムネイル**: 各候補は現在のキャラにそのパーツを当てはめた状態で描画 → 「付けたらどうなるか」が一覧で分かる
- **カテゴリ別ズーム**: 目タブでは目元だけ、口タブでは口元だけを拡大表示し、微差を比較しやすく
- **形×サイズのマトリクス配列**: 同じ形が5〜7段階のサイズ順に並ぶので「この形のもう少し大きいの」がすぐ隣にある
- **色は数値でなくスウォッチグリッド**(アンダートーン×明度)+仕上げの濃さスライダー
- **左側プレビューは常時固定表示**(sticky)。どのタブでも結果が即見える

## 5. AI「似顔絵自動生成・微調整」の実現方向性

- **フェーズ1(実装済み・β)**: ブラウザ内Canvasで写真を縮小解析し、肌領域・髪領域の代表色を推定 → 最も近いスウォッチと髪型候補を自動選択。サーバ送信ゼロでプライバシー安全、難易度低
- **フェーズ2(次段階)**: MediaPipe Face Mesh等のオンデバイス顔ランドマーク検出で、輪郭の縦横比・目の間隔/傾き・口の幅などを数値化し、対応するパーツ+スライダー初期値へマッピング。難易度中(JSライブラリで完結、追加サーバ不要)
- **フェーズ3(研究的)**: マルチモーダルLLM APIに「この写真に近いパーツID構成」を提案させる。精度は高いがAPIコスト・写真送信の同意設計が必要。難易度中〜高
- **注意点(重要)**: 実在の人物(有名人・友人)の写真を扱う場合も、あくまで「デフォルメされたキャラ風」の再現に留める。写真は端末外に出さない設計を維持し、他人の写真は本人(子どもの場合は保護者)の同意を前提とする旨をUI/マニュアルに明記。有名人の肖像を商用利用しない前提のファン用途に限定

## 6. マネタイズ案

- **プレミアムパーツパック**(季節衣装・ご当地小物など)の買い切り課金
- **PNG高解像度/背景付き書き出し**の有料化(通常書き出しは無料のまま)
- **学校・イベント向けカスタマイズ提供**(文化祭・結婚式のウェルカムボード用など)
- 広告は体験を損なうため非推奨。入れるなら保存完了画面のみ

## 7. MVP優先順位(今回の実装範囲)

1. ✅ パーツ選択(全12カテゴリ・各50種以上)+ リアルタイムプレビュー
2. ✅ 微調整スライダー(色の濃さ・位置・サイズ)
3. ✅ 保存・コレクション管理(一覧/再編集/削除)
4. ✅ PNG書き出し・JSON交換
5. ✅ AIサジェストβ(写真→肌・髪色・髪型候補)
6. ⬜ フェーズ2: 顔ランドマークによる輪郭・目鼻口の自動マッピング
7. ⬜ 共有URL(キャラ構成をURLパラメータ化して1タップ共有)
