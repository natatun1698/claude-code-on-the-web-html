# データの書き方(仮スキーマ)

このフォルダは、過去問の書き起こしデータです。アプリのコードとは分けています。
ファイル名: `problems-{年度}-{回}.json`(1つの試験につき1ファイル)、図は `figures/{id}.svg`。

## 1問の項目
| 項目 | 内容 |
|---|---|
| `id` | `年度-回-大問-小問`(例 `2025-1-2-3`)。図が複数問で共有されるときは `年度-回-大問.svg` |
| `source` | `{year, round, big, no}` |
| `tags` | `大分類/小分類` の配列(分野の分類表に従う) |
| `pattern` | 解法パターン名(「もう一問」の検索に使う) |
| `text` | 問題文。分数は `{{5/8}}`、帯分数は `{{2 1/13}}`(アプリ側で縦書きの分数に直す) |
| `figure` | 図のSVGへの相対パス(なければ省略) |
| `answerType` | `int` / `dec` / `frac` / `multi` / `ordered` / `time`(単位は `unit` に別に書く) |
| `answer` | `int/dec/frac` は文字列(例 `"7/8"`)。`multi`・`ordered` は文字列の配列。`time` は `{hours, minutes, seconds}` |
| `unit` | 答えの単位(表示用)。なければ省略 |
| `orderMatters` / `labels` | `multi` のみ。`orderMatters: true` のとき、`labels` の順(ア・イなど)に答える |
| `choices` | `ordered` のときの選択肢 |
| `essence` | 本質的に何を聞いているか |
| `hint1`, `hint2` | 段階ヒント |
| `exp` | 解説(公式解説の丸写しではなく、小5向けに書き直したもの) |
| `realworld` | 社会での役立ち(任意) |
| `dependsOn` | 前の小問の結果を問題文に含めているときの、元の問題のID(任意) |
| `status` | `ready` または `excluded`(`excluded` のときは `reason` を書く。出題しない) |

## 書き起こしの方針
- 公式解答が読み取れない、または図が確定できない問題は、推測で埋めず `excluded` にする。
- 小問が前の小問の答えに依存する場合は、必要な値を問題文に含めて、単独で解けるようにする。
- 図は写真を使わず、1問ごとにSVGで描き直す。
