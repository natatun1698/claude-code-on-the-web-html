# 🐱 ねこさんすう

小5〜小6の中学受験算数向け「一問一答」アプリ。スコティッシュフォールドの猫が過去問(原題)を出題し、
アプリ内の数字キーで答え、まちがえたらヒント1→ヒント2→解説の順に学べます。
iPad(Safari・ホーム画面に追加)向け。ビルド不要・外部通信なし・進捗は端末内(localStorage)に保存。

> **家庭学習用です。** 問題データは `data/` フォルダにだけ入っており、アプリのコードとは分かれています。

## 使い方
1. `index.html` を HTTP サーバー経由で開く(GitHub Pages なら `/neko-sansu/`。`fetch` を使うため `file://` では動きません)。
   ローカルでは リポジトリ直下で `python3 -m http.server` → `http://localhost:8000/neko-sansu/`。
   iPad では共有メニューから「ホーム画面に追加」。一度開けば `sw.js` がキャッシュしてオフラインでも動きます。
2. 初回に猫の名前を付ける。
3. 「もんだいを とく」→ 猫が出題 → 紙に書いて考える → 数字キーで入力 → 「こたえる」。
   - 分数は `/` キー、帯分数は `と` キー(例 `2と1/13`)。複数の答えは `,` で区切る。時間は `時間` `分` `秒` キー。
   - 並べ替え・記号を選ぶ問題は、選択肢のボタンをタップする。
   - 右下の進むボタン: 「わからない」→ ヒント1 →「つぎのヒント」→ ヒント2 →「かいせつを 見る」→ 解説(「この問題は なにを 聞いているか」を必ず表示)。
   - 正解・解説のあとは「もう一問」で同じ解き方(`pattern`)の別の問題。無ければ同じ分野から。「おわる」でホームへ。
   - 「← 前の問題に もどる」で前の問題へ。回答済みなら結果と解説、未回答なら出題の状態に戻ります。
   - 「社会で どう役立つ?」ボタンは、たまに出ます(毎回ではありません)。
4. 「ずかん」で猫の紹介(品種・折れ耳)、「せいせき」で分野別の正解率。
5. 間違えた問題は翌日以降に優先して再出題されます。

全画面に「← もどる」(左)と「ホームへ」があり、ブラウザの戻る/進む・iPad のスワイプ戻ると同じ動きをします。
いちばん下まで戻ってもアプリは閉じず、タイトルに戻ります。

## 保護者画面
タイトル画面の猫を**長押し**(約1秒)→ 4桁の暗証番号(初回入力が設定になる)。
- 日別の実施数、分野別の正答率、途中でやめた問題、3分以上かかった問題(ヒント回数・やり直し回数つき)、問題データの件数
- 「記録を書き出す」で JSON をファイルに保存、「記録を読み込む」で復元(重複は自動で除く)
- 記録には問題 ID だけが入り、問題文は入りません。

学習の状態は 6 つ: 未着手 / 途中離脱 / 正解(ノーヒント) / ヒントを見て正解 / 不正解のまま終了 / 解説を見て終了。
途中離脱は「開始の記録があって終了の記録がない」ことから判定し、次回起動時に猫が「つづきから やる?」と聞きます(責めません)。
1問ごとに、かかった時間・ヒント使用回数・入力のやり直し回数・日時を記録します。

## 問題データ
- `data/index.json` … 読み込むファイルの一覧
- `data/problems-{年度}-{回}.json` … 1試験1ファイル(JSON配列)。`status: "excluded"` の問題は出題しません
- `data/figures/{id}.svg` … 手描きの図(写真は使わない)
- 項目の説明・年度の追加手順はスキル `.claude/skills/neko-sansu/`(`references/add-problems.md`)を参照

## 開発
- 構成: `index.html` / `style.css` / `app.js`(UI) / `cat.js`(猫SVG) / `judge.js`(採点) / `problems.js`(読み込み・検証・出題) / `nav.js`(画面遷移) / `history.js`(履歴) / `sw.js`(オフライン)
- テスト: `node neko-sansu/tests/run.js`
  - `data`: スキーマ・ID重複・分野一覧・図の存在とXML・禁止語(学校名・出版社名)
  - `judge`: 採点(分数・小数・単位・全角・順不同・時間・文字の選択肢)
  - `history`: 履歴の記録と離脱の検知、バックアップ/復元
  - `nav`: 画面遷移(戻る・進むの繰り返し)、問題の前後移動
  - `pick`: 「もう一問」の選び方(同じ `pattern` → 同じ分野)、重み付き出題
