# 🐱 ねこさんすう

小5〜小6の中学受験算数向け「一問一答」アプリ。スコティッシュフォールドの猫が出題し、
アプリ内の数字キーで答え、まちがえたらヒント1→ヒント2→解説の順に学べます。
iPad(Safari・ホーム画面に追加)向け。ビルド不要・オフライン・外部通信なし。

> **家庭学習用です。このリポジトリに入試の過去問は含まれていません。**
> 問題はすべて、数値がランダムに変わるオリジナルの類題テンプレートです。
> 原題を使いたい場合は、下記の手順で各自の端末内にだけ取り込みます(公開されません)。

## 使い方
1. `index.html` を開く(GitHub Pages なら `/neko-sansu/`)。iPad では共有メニューから「ホーム画面に追加」。
2. 初回に猫の名前を付ける。
3. 「もんだいを とく」→ 猫が出題 → 紙に書いて考える → 数字キーで入力 → 「こたえる」。
   - 分数は `/` キー、帯分数は `と` キー(例 `1と1/4`)。複数の答えは `,` で区切る。
   - 2回まちがえるとヒント1が出る。ヒント2 → 解説の順に開ける。
   - 正解・解説のあとは「もう一問 やってみる」で同じ型の別の問題が出る。
4. 「ずかん」で猫の紹介、「せいせき」で分野別の正解率。

## 保護者画面
タイトル画面の猫を**長押し**(約1秒)→ 4桁の暗証番号(初回入力が設定になる)。
- 日別の実施数、分野別の正答率、途中でやめた問題、3分以上かかった問題の一覧
- 「記録を書き出す」で JSON をファイルに保存、「記録を読み込む」で復元(重複は自動で除く)
- 記録には問題 ID だけが入り、問題文は入りません。

学習の状態は 6 つ: 未着手 / 途中離脱 / 正解(ノーヒント) / ヒントを見て正解 / 不正解のまま終了 / 解説を見て終了。
途中離脱は「開始の記録があって終了の記録がない」ことから判定し、次回起動時に猫が「つづきから やる?」と聞きます。

## 原題(私用バンク)の取り込み手順
1. 下の形式で JSON ファイルを作り、iPad の「ファイル」アプリに保存する(例 `genda-2024.json`)。
2. タイトル画面の「原題を 取りこむ」→ ファイルを選ぶ。
3. 形式に誤りがあれば行番号つきで表示され、1 件でもあれば保存されません。
4. 取り込んだ問題は端末の IndexedDB にだけ保存され、出題の約3割に混ざります。「取りこんだ原題を すべて消す」で全削除。

```json
{
  "version": 1,
  "problems": [
    {
      "id": "2024-1-01",
      "tags": ["計算", "四則計算・逆算"],
      "text": "問題文(HTML可)",
      "answerType": "int",
      "answer": 1981,
      "hint1": "……", "hint2": "……", "exp": "……",
      "essence": "この問題が本質的に聞いていること", "pattern": "逆算",
      "templateId": "gyakusan"
    },
    { "id": "2024-1-05", "tags": ["計算", "四則計算・逆算"], "text": "……", "answerType": "frac", "answer": { "n": 1, "d": 4 } },
    { "id": "2024-2-03", "tags": ["速さ", "旅人算"], "text": "……", "answerType": "time", "answer": { "m": 5, "s": 30 } },
    { "id": "2024-2-06", "tags": ["図形", "角度・面積・長さ"], "text": "……", "figure": "<svg viewBox='0 0 320 220'>…</svg>", "answerType": "dec", "answer": 21.5, "unit": "cm²" }
  ]
}
```
- `answerType`: `int` `dec` `frac`(`{"n","d"}`) `unit` `time`(`{"h","m","s"}`) `multi`(配列・順不同) `ordered`(配列・順序あり) `choice`(`choices` 配列と index)
- `tags[0]` は 計算 / 和と差 / 割合と比 / 速さ / 図形 / 表とグラフ / 数の性質 / 規則性 / 場合の数 のいずれか
- `figure` はインライン SVG のみ(`<script>` `<img>` `on〜=` は拒否)
- `.gitignore` により `neko-sansu/**/*.json` はコミットされません。

## 開発
- 構成: `index.html` / `style.css` / `app.js`(UI) / `cat.js`(猫SVG) / `rng.js` / `judge.js`(採点) / `history.js`(履歴) / `importer.js`(取り込み) / `templates/`(類題テンプレート)
- テスト: `node neko-sansu/tests/run.js`(テンプレートを seed 300 通りで生成し型・別解・解説の数値を検査、採点・履歴・取り込み・著作権チェック)
- 類題の追加手順はスキル `.claude/skills/neko-sansu/` を参照(`references/add-problems.md`)
