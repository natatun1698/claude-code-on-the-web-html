# 📷 ねこさんすう 写真版

[ねこさんすう](../neko-sansu/) の姉妹アプリ。原題を **JSON ではなく写真(JPEG など)で取りこみ**、
おうちの人が答えを登録しておくと、子どもがアプリ内の数字キーで答えて自動採点されます。
`/neko-sansu/` とは **保存データが完全に別**なので、2 つを並行して使えます。

> **家庭学習用です。写真はこの端末の IndexedDB にだけ保存され、リポジトリにも外部にも送られません。**
> リポジトリに入っているのは数値がランダムに変わるオリジナルの類題テンプレート(`../neko-sansu/templates/`)だけです。

## /neko-sansu/ との違い
| | ねこさんすう | ねこさんすう 写真版 |
|---|---|---|
| 原題の取りこみ | JSON ファイル | 写真(カメラ/フォトライブラリ、複数可)+ 画面で答えを入力 |
| 答えの登録 | JSON に書く | フォームに `12`・`3/4`・`1と1/4`・`5分30秒`・`3,5,8` のように入力。答えを登録せず「じぶんで まるつけ」も可 |
| 解説 | JSON の文字列 | 文章と/または **解説の写真** |
| 保存先 | `neko-sansu-v1` / `neko-sansu-log-v1` / IndexedDB `neko-sansu` | `neko-sansu-photo-v1` / `neko-sansu-photo-log-v1` / IndexedDB `neko-sansu-photo` |
| 出題 | 類題 + 原題 3 割 | 「写真だけ」か「写真と類題を半々」を選べる |
| 共用コード | ― | `../neko-sansu/` の `rng.js` `judge.js` `cat.js` `history.js` `templates/` をそのまま読み込む |

## 使い方(おうちの人)
1. `index.html` を開く(GitHub Pages なら `/neko-sansu-photo/`)。iPad では「ホーム画面に追加」。
2. タイトル → 「写真を 取りこむ」 → 「📷 カメラで とる」か「🖼 写真を えらぶ(複数可)」。
3. 1 枚ずつ登録画面が開くので、**分野**・**答えの型**・**答え**を入れて「保存する」。複数枚を選んだときは保存すると次の写真に進みます。
   - 答えの型: 整数 / 小数 / 分数 / 単位つき / 時間 / 複数(順不同・順番あり) / 選択肢 / **答えを登録しない**(子どもが答えたあと解説を見せて ⭕❌ を自分で付ける)
   - 任意: 小分野、ヒント1・2、解説(文)、解説の写真、本質(1文)、解法パターン名、「もう一問」で出す類題テンプレート、メモ(出典など。子どもには見えません)
4. 「出し方」で「写真の もんだいだけ」か「写真と 類題を まぜる」を選ぶ。
5. 取りこんだ写真の一覧をタップすると直せます。「この問題を 消す」で 1 問ずつ、「すべて消す」で全削除。

写真は長辺 1600px の JPEG に縮小して保存します(iPad の写真は大きいため)。

## 使い方(子ども)
`/neko-sansu/` と同じ。写真をタップ(または「🔍 大きく 見る」)で拡大、2 回まちがえるとヒント → 解説。
答えが登録されていない問題は「こたえる」のあとに解説が出て、「⭕️ あっていた / ❌ ちがっていた」を自分で押します。

## 画面の行き来
画面を切り替えるたびにブラウザの履歴に 1 つ積むので、**ブラウザ(やスワイプ)の「戻る」「進む」で前の画面に戻れます**。
各画面の左上にも「← もどる」があり、問題の途中で戻っても「進む」やタイトルの「つづきから」で同じ問題に戻れます。
開き直したときは必ずタイトルから始まります。

## 保護者画面
タイトルの猫を長押し(約 1 秒)→ 4 桁の暗証番号。内容は `/neko-sansu/` と同じ(日別・分野別・離脱・時間がかかった問題、記録の書き出し/読み込み)。
記録には問題 ID だけが入り、写真は入りません。写真の問題は一覧で「📷 分野・メモ」と表示されます。

## 開発
- テスト: `node neko-sansu-photo/tests/run.js`(答え文字列の解析・フォーム検証・履歴の分離・著作権チェック)。共用ロジックは `node neko-sansu/tests/run.js`。
- `.gitignore` で `neko-sansu-photo/` 配下の画像と JSON を除外しています。写真を誤ってコミットしないでください。
- 類題テンプレートを増やしたいときは `/neko-sansu/` 側に追加すれば、このアプリにも自動で反映されます(スキル `.claude/skills/neko-sansu/`)。
