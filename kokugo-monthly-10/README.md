# 🎤 ことだま☆5と国語ライブ ― マンスリーテスト10月号(国語)

キャンパス マンスリーテスト「国語 10月号」(5後期)の復習アプリ。
架空の男性アイドルグループ「ことだま☆5」の5人が大問を1つずつ担当し、えらんだ**推しメン**が画面のすみで応援してくれます。

- HTML / CSS / JavaScript のみ・ビルド不要。`index.html` をブラウザで開けば動きます。
- 外部通信なし。進捗は localStorage(キー `kokugo-monthly10-v1`)にのみ保存。
- 得点・偏差値・順位は表示しません。まちがえたときは💡と解説でやさしくフォローします。
- 名前は `app.js` 先頭の `NAME` で変更できます。

## モード
- 💖 推しと特訓モード … 10問。アプリ内でまちがえた問題が出やすくなります。
- 🎤 ライブ本番モード … 31問を大問順に。
- 🔁 アンコールモード … アプリ内でまちがえた問題だけ。
- 🎯 メンバー指名 … 大問ごとに練習。

最後に「アンコール」でまちがえた問題をもう一度だけ出題します。

## 採点メモ
- 大問2(2)「鉄棒」、(3)「せかい」などは不正解にせず「ひらがなで」「書いてあるとおりに」とやり直しを促します。
